# 404 上游牧场适配

本轮以本地只读源码 `qq-farm-bot-404` 的提交 `11d91147a47579e16cdeaa2dc6f329a8630f945c` 为主要来源，将牧场作为独立子系统接入现有项目。源仓的启动脚本和未提交文件不参与覆盖。

## 替换范围

- 旧局部 `animalpb.proto`、9 个分散牧场接口和旧巡查配置由独立 `ranch.proto`、`ranch-protocol`、完整牧场服务及策略配置替代。
- 独立协议描述器覆盖动物、设施、仓库、商店、图鉴、订单、任务和好友互动。`FeedAnimal` 字段 2 为罐头类型 `bucket_type`，不再按旧实现解释为投喂数量；历史 HAR 字节回归保留在 `animal-proto.test.js`。
- 新资源接口为 `/api/ranch/status` 及 `/api/ranch/{friends,activity,shop,illustrated,analytics,profile}`，写操作统一经 `/api/ranch/action`；策略通过专用 `/api/ranch/settings` 保存、校验和按账号广播。
- 使用 `ranch_auto_*` 开关和对象型 `ranch_policy`，新开关默认关闭。旧配置不会自动开启消费或互动行为，旧标量与旧开关不作为新策略输入。
- 前端使用上游牧场概览、个人、好友、商城、图鉴和分析页面，保留主项目原有全局农场 / 牧场切换按钮、持久化空间及主活动入口。

## 保留边界

农场业务、多用户权限、账号配置隔离、好友页精简、仓库自动出售保留牧草以及部署镜像回退改动继续保留。共享 Worker、网络、配置模型和路由采用局部合并，不用上游整文件替换。

牧场协议使用独立 protobuf root，不将平铺 `ranchbridge` 消息拼入现有农场协议 root。现代登录仅补充 `PlayerLogin` 消息及场景协调所需绑定。场景 lease 负责完整农场 / 牧场事务；停止、重连和账号生命周期变化必须取消旧代次任务。游戏写操作不会因超时自动重放。

直连与网关能力分别检查；现有网关协议没有跨进程场景事务能力时，牧场切场应明确返回不支持，不能将未确认的场景状态视为已连接。

## 历史材料

`ranch-protocol-analysis.md` 和 `ranch-har-20261117.md` 保留为旧方案的证据归档，其中旧接口、字段语义和「尚未实现」的说明不代表当前版本。不得按历史文档恢复旧协议或并行运行两套巡查。

## 验收范围

本轮验证限于离线协议向量、服务和策略测试、账号隔离、后端回归以及前端类型检查和构建。不启动浏览器，不使用真实游戏账号，不包含服务器镜像实际拉取或游戏在线验收。未获用户本地测试后明确授权前不推送、不发布。

2026-11-17 离线验收结果：牧场与登录协议专项 288/288 通过；全量后端 961 项中 959 项通过，剩余两项为迁移前已存在的 Python 解释器不可用和已过期奶茶活动配置测试失败。随后新增的统一调度器早退回归单独 1/1 通过，确认网关退避后不会永久占用运行标志。最终 `vue-tsc -b && vite build` 成功（477 模块）；`git diff --check` 通过，仅提示部分既有 CRLF 行尾。新牧场开关默认关闭，需按账号在牧场设置中启用。
